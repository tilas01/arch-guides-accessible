# Dependency Archive

This directory contains scripts and archived repositories for crucial dependencies used by the *nix Guides project. 
If the original repositories or YouTube tutorials ever go offline, this archive ensures the project remains 100% reproducible and usable.

## Included Archives
- **Dusky OS** (Creator: dusklinux)
- **OpenDoas** (Creator: Duncaen)

Run `backup_dependencies.sh` to fetch the latest clones of these repositories into this folder.
Please credit the original authors when distributing these archives.
