Arch Rusty Security Suite (ARSS)

Memory-safe, highly optimized kernel and userspace daemon suite written entirely in Rust.

💡 Architecture Parity: All tools in this suite support strict Headless CLI arguments, an Interactive Terminal Wizard (-i), and native X11/Wayland GUI instances (--gui).

🦆 Anti-Ducky Rust Daemon

A keystroke injection defense daemon that monitors `udev` and `evdev` for impossibly fast typing speeds indicative of a Rubber Ducky or BadUSB attack.

Usage

# Start the daemon in the background
sudo systemctl start anti-ducky

# Interactive configuration wizard
sudo anti-ducky --interactive

# Launch the graphical control panel (X11/Wayland)
sudo anti-ducky --gui

🦀 ARSS Firewall Rust eBPF

A state-of-the-art interactive firewall utilizing eBPF (XDP/TC hooks) to intercept network packets directly in the kernel, achieving orders of magnitude lower latency than traditional iptables. Provides a "Little Snitch" style interactive experience.

Usage

# Headless CLI: Block an IP immediately
sudo arss-firewall --block 1.1.1.1

# Interactive TUI Wizard
sudo arss-firewall -i

# Graphical Control Panel (Requires display server)
sudo arss-firewall --gui

👁️ Scarecrow Rust eBPF

Advanced network monitor and anomaly detector. Maps processes to their network sockets in real-time utilizing eBPF kprobes, bypassing user-space obfuscation techniques.

Usage

# Run headless monitor and log to /var/log/scarecrow
sudo scarecrow --daemon

# Launch Interactive CLI interface
scarecrow -i

🛡️ Kernel Watcher Rust eBPF

Guards critical kernel data structures against unauthorized modifications. Uses eBPF tracepoints to log module loading and memory writes in real-time.

🔑 Libre OTP Rust PAM

A Pluggable Authentication Module (PAM) written in Rust that enforces Time-based One-Time Passwords (TOTP) during TTY, SSH, or Desktop Environment logins.
