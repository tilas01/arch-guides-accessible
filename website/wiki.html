This wiki provides comprehensive, modular documentation covering every aspect of the Arch Linux installation process — from pre-installation to advanced security hardening with the Arch Rusty Security Suite by tilas01.

📖 Manual vs Generator

The auto script generator is optional. This wiki has full parity with every generator selection — every dropdown option is explained in detail so you can manually configure your system using only native tools and this documentation.

See All Generator Selections Explained for a complete reference of every option and recommended configuration.

📦 Releases & Integrity

All security tools are available as reproducible releases with SHA256 hashes and GPG signatures. You can verify integrity manually or use the included verification tool. See the wiki section on integrity verification for full instructions.
