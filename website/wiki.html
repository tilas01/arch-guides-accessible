🔐 Libre-OTP (Boot & Login 2FA)

Libre-OTP integrates TOTP (Time-Based One-Time Passwords) directly into the Linux PAM (Pluggable Authentication Modules) stack. This enforces two-factor authentication before decryption at boot, upon logging into the TTY, or when accessing the system via SSH.

Features

  • Escalating Bruteforce Lockout: Prevents bruteforce attacks by locking the system for 30 minutes after 3 failed attempts, adding 30 minutes for every subsequent failure (max 24 hours).
  • Lockout Bypass: Set a cryptographically unique bypass password (Argon2id hashed) to manually override the lockout timer.
  • KeePassXC Integration: Automatically generates an importable CSV for KeePassXC to securely store your recovery codes.
  • Supports SHA-1, SHA-256, and SHA-512 hashing algorithms.
  • Generates offline recovery codes of custom length for emergency access.
Warning: Losing your Authenticator App and Recovery Codes will result in permanent loss of access to your machine.

🛡️ Input Guard (Anti-Ducky)

Input Guard is a robust USB HID sandbox designed to defeat malicious hardware like the USB Rubber Ducky, Bash Bunny, or compromised O.MG cables.

How it Works

Upon installation, Input Guard catalogs all currently connected USB devices. Any new HID (Human Interface Device) plugged into the system is automatically blocked until manually authorized via the CLI tool. It also monitors typing speed heuristics—if an "authorized" keyboard begins typing at 10,000 WPM, it is immediately severed and flagged as a spoofed malicious device.

🔍 ISO Verification & Integrity

Before installing Arch Linux, it is critical to verify that the `.iso` image was not tampered with during download. This module automatically fetches the official SHA-256 checksums from the Arch Linux mirrors and verifies your local or USB-mounted ISO image.

☠️ Panic Password (Duress Wipe)

The Panic Password module provides emergency duress protection. When you install ARSS, you can set a secondary LUKS decryption password.

Mechanics

If you are compelled to unlock your device under duress, entering the Panic Password (instead of your real password) twice in a row triggers an immediate, irreversible DoD 3-pass overwrite of your entire LUKS header and partition data. The system will be permanently destroyed, rendering all encrypted data mathematically unrecoverable.

📱 Notification Webhooks

Connects ARSS directly to your mobile device via Webhooks. The suite natively supports ntfy.sh (a free, open-source, no-signup push notification service), but can be configured for Discord, Slack, Bark, or custom JSON payloads.

Whenever the Kernel Watcher detects malware, or Anti-Evil-Maid detects tampering, an instant push notification is fired to your phone.

🔒 Hardened SSH + OTP

This module aggressively hardens the OpenSSH daemon by enforcing the strictest cryptographic standards.

  • Disables Root Login entirely.
  • Disables Password Authentication entirely.
  • Enforces `Ed25519` keys only.
  • Enforces `chacha20-poly1305` and `aes256-gcm` ciphers.
  • Pairs with Libre-OTP to require both a private key file AND a time-based 2FA token to authenticate.

🕵️ Anti-Evil Maid (AEM)

The "Evil Maid" attack occurs when an attacker gains brief physical access to your unattended machine and modifies the unencrypted `/boot` partition (e.g., injecting a keylogger into the kernel or initramfs) to steal your LUKS decryption password the next time you boot.

ARSS AEM creates decoy kernel images and verifies the cryptographic checksum of the real kernel on every boot. If the checksum mismatches, it alerts you via webhook and halts the boot sequence.

🥷 Kloak Anonymizer

kloak (by vmonaco) is a keystroke anonymization tool. Modern behavioral biometrics can uniquely identify you simply by analyzing the millisecond delays between your keystrokes. Kloak intercepts raw `/dev/input` events and obfuscates the timing, making your typing pattern completely unidentifiable to web trackers and malware.

👁️ Malicious Kernel Behavior Watcher (Semi-EDR)

The ARSS Kernel Watcher acts as an asynchronous, highly-optimized semi-EDR (Endpoint Detection and Response) daemon written in Rust.

Infostealer & Exploit Protection

It utilizes high-performance filesystem monitoring and system heuristics to detect unauthorized access to critical configuration files (`/boot`, `cron`, `ld.so.preload`) as well as highly sensitive data structures like SSH keys, AWS credentials, browser cookies, and your KeePassXC ARSS Database.

If an infostealer or rootkit attempts to exfiltrate or modify these files, Kernel Watcher instantly triggers a quarantine action and sends a push notification to your phone.

📄 Quick-Reference Cheatsheets

Use these cheatsheets to quickly reference Arch Linux commands and Desktop Environment workflows.

Arch Linux Commands

  • Update System: sudo pacman -Syu (or paru -Syu for AUR)
  • Install Package: sudo pacman -S package_name
  • Remove Package: sudo pacman -Rns package_name
  • Enable Service: sudo systemctl enable --now service_name
  • Check Service Logs: journalctl -u service_name -e
  • Create BTRFS Snapshot: sudo snapper create -c timeline -d "Manual backup"

👻 Libre-Cyber-ScareCrow (Sandbox Spoofing)

Advanced malware and infostealers often possess "anti-analysis" killswitches. If they detect they are inside a Virtual Machine (VM) or a security researcher's sandbox, they immediately self-terminate to avoid detection.

Libre-Cyber-ScareCrow weaponizes this behavior. It turns your bare-metal Arch Linux installation into a "fake" analysis environment by spawning lightweight, sleeping dummy processes (`VBoxService`, `vmtoolsd`, `wireshark`, `ida64`) and creating fake sandbox artifacts (`/tmp/cuckoo`).

When malware lands on your system and scans the process tree, it will be tricked into thinking it is inside a hostile security sandbox, triggering its own killswitch and destroying itself before executing its payload.
