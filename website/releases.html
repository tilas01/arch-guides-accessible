🔒 Integrity Verification (GPG & Hashes)

All pre-compiled standalone security tools are cryptographically signed using GPG and hashed to ensure build integrity. The public GPG key (tilas01.asc) is available in the root of the repository.

1. Import the public key:

gpg --import tilas01.asc

2. Verify the GPG signature:

gpg --verify tool_name.sig tool_name

3. Verify the SHA-512 hash:

sha512sum -c tool_name.sha512
