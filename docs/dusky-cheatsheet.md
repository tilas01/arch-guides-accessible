# OS Shortcut & Command cheatsheet for dusky 2026 os release

[Dusky OS by dusklinux](https://github.com/dusklinux/dusky) is a fully riced, incredibly fast Arch Linux setup.
If you selected **Dusky OS** in the script generator, it will be automatically cloned and installed for you!

**Creator**: [dusklinux on GitHub](https://github.com/dusklinux) | [YouTube Showcase](https://www.youtube.com/watch?v=JmgvSdEIK8c)

## Essential Shortcuts

| Keybinding | Action |
|------------|--------|
| `Super + Enter` | Open Terminal |
| `Super + d` | Open App Launcher (Rofi/Dmenu) |
| `Super + Shift + q` | Close current window |
| `Super + 1-9` | Switch to workspace 1-9 |
| `Super + Shift + 1-9` | Move window to workspace 1-9 |
| `Super + Space` | Toggle floating layout |
| `Super + f` | Toggle fullscreen |
| `Super + Shift + r` | Reload window manager |
| `Super + Shift + e` | Exit / Logout |

## Root Account & Usage
With Dusky OS, it is recommended to run as your regular user and elevate privileges using `sudo` or `doas` when necessary. If you selected "No" for Root SSH Access in the generator, you cannot SSH directly into the root account, which is best for security!
